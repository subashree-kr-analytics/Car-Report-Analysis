# Car Report Analysis 🚗

## Overview
This Power BI report analyzes car-related data to identify trends, performance insights, and key metrics through interactive visualizations.

## Tools Used
- Power BI
- Excel

## Features
- Car Performance Analysis
- Sales and Trend Insights
- Interactive Filters and Slicers
- KPI Cards and Visual Reports
- Multi-Page Dashboard Report

## Files Included
- Power BI Report File (.pbix)
- Dataset Files
- Dashboard Screenshots
